# 🎮 سيد & ياسمين — The Endless Odyssey

**لعبة منصّات وألغاز تعاونية (Co-op) لاعبَين عبر الإنترنت** — مبنية خصيصاً لـ **سيد وياسمين**، بأوجهما الحقيقية كشخصيات داخل اللعبة.

تصميمها فلسفيّاً مزيج بين **Super Mario** (المنصّات والفيزياء)، **Pepelo / It Takes Two** (الألغاز التعاونية والاعتماد المتبادل بين الشخصيّتين)، و**Portal-like logic** (حلّ الألغاز الصعبة بالتعاون). اللعبة **أونلاين عبر Peer-to-Peer (WebRTC)** — بدون أي سيرفر لوجيك.

> ⚠️ اللعبة تدعم **أونلاين 2 لاعب** (كل واحد على جهازه) **+ لعب محلي لاعبان على نفس الشاشة** (للتجربة بسهولة).

---

## ✨ الميزات

- **بطلان بشروط مختلفة**: **سيد** قوي (يرمي، يسحب الرافعات الثقيلة، يكسر الصناديق) و **ياسمين** رشيقة (قفزة مزدوجة، تختـرق اللوحات الإلكترونية، تُضيء جسور النور).
- **تعاون إجباري (It Takes Two-style)**:
  - سيد يرمي ياسمين عبر هاوية واسعة، وهي تختـرق الشقّ لتنير جسراً يعبره.
  - الوقوف معاً على لوحتَين لفتح البوابة، أو لتشغيل المولد، أو لرفع المصعد.
  - تحريك صناديق ثقيلة فوق لوحات الضغط.
  - **مواجهات**: أعداء (سلايْم يزحف + طيّار يحلّق) يمكن دهسهم بالقفز (Stomp) وإلا أصابوك.
  - **تقدّم المرحلة بيد المضيف (Host)**: عندما تُكملان عالماً، المضيف هو من يضغط "متابعة" ليأخذكما للعالم التالي؛ الضيف يتبع تلقائياً.
  - **تزامن كامل للعالم**: القطع والعملات والصناديق والبوابات والجسور النورانية كلها تتزامن لحظياً بين اللاعبَين (بقاعدة Host-authoritative).
- **ألغاز صعبة ومتنوعة**: لوحات ضغط، روافع، محطات اختراق، أبواب وبوابات، جسور نور، أحزمة ناقلة، نوابض، مراوح، أرض جليد، جسور متأكّلة، ممرّات ليزر متوقّتة، بوابات نقل (Teleport)، أعداء، ونقاط حفظ.
- **8 عوالم متقنة** بمواضيع ومراحل متدرّجة الصعوبة (1 → 8) + **زعيمان**: جوليم (3 ضربات) في العالم 5، و"نكس الفراغ" (5 ضربات، أسرع) في العالم 8 — كلاهما يتطلّب وقوف اللاعبَين معاً على اللوحتين أثناء انخفاض الدرع.
- **نظام مراحل “Modular”**: أي عالم جديد = ملف واحد في `levels/` + سطر في `levels/index.js`. لا حاجة للمس المحرك.
- **نظام شبكة PeerJS (WebRTC)**: رمز غرفة قصير تشاركه مع شريكك، واتصال مباشر بلا سيرفر.
- **صوت WebAudio** مولّد لحظياً (بدون ملفات صوت) + مؤثرات بصرية + واجهة عربية RTL جميلة.

## 🕹️ التحكـّم (Control)

| الحركة | **سيد** (P1) | **ياسمين** (P2) |
|---|---|---|
| يمين / يسار | `D` / `A` | `→` / `←` |
| قفز | `Space` أو `W` | `↑` |
| قفزة مزدوجة | — | اضغط `↑` ثانية في الهواء |
| تفاعل (رافعة / اختراق) | `F` | `E` |
| رمي ياسمين | `Q` (وهو قربها) | — |

> في الوضع **الأونلاين**: كل لاعب يستخدم تحكّم شخصيّته على جهازه.
> في الوضع **المحلي**: كلاهما على نفس الجهاز (سيد A/D/W، ياسمين أسهم).

## ☁️ النشر على Vercel (أونلاين)

اللعبة جاهزة للنشر المباشر. طريقتان:

### الطريقة 1 — السحب من GitHub (الأسهل والأكثر استمرارية)

1. أنشئ مستودعاً جديداً على GitHub (حيث `sayed-yasmin-endless-odyssey`).
2. ادفع الكود إليه:
   ```bash
   cd sayed-yasmin-odyssey
   git init
   git add .
   git commit -m "Sayed & Yasmin: The Endless Odyssey — v1.0"
   git branch -M main
   git remote add origin https://github.com/<YOUR_USER>/<REPO>.git
   git push -u origin main
   ```
3. اذهب إلى [vercel.com](https://vercel.com) → **Add New → Project** → import المستودع.
4. العداد التلقائي (framework: **Next.js**) يختار كل شيء. اضغط **Deploy**.

### الطريقة 2 — CLI مباشرة (بدون GitHub)

```bash
npm i -g vercel
vercel --prod
```
(أجب على الأسئلة باختيار Next.js وبنفس إعدادات النشر.)

> **مهم للـ WebRTC:** اللعبة تستخدم خادم إشارات PeerJS المجاني (`0.peerjs.com`). لا يحتاج أي إعداد. تأكد أن الموقع **https** (Vercel يوفّره تلقائياً) لأن WebRTC يتطلب Secure Context.

## 🧩 إضافة عالم / مرحلة جديدة (Modular)

1. أنشئ `src/lib/game/levels/world-9.js` مستخدِماً الدوال من `helpers.js`.
2. عرّف `spawn` و `goal` و `platforms` و `objects` و `coins` و `hints` و `decorations` (وأيضاً `boss` اختيارياً).
3. أضِفه في `levels/index.js`:
   ```js
   import world9 from './world-9.js';
   export const LEVELS = [world1, world2, world3, world4, world5, world6, world7, world8, world9];
   ```
4. حدّث `TOTAL_LEVELS` في `components/UIOverlay.js`.

> القاعدة الذهبية: **تقدّم المرحلة يبقى على مستوى الأرض**؛ الارتفاعات الكبيرة للنجوم (اختيارية) فقط. أبعد قفزة أفقية آمنة ≈ 170px لسيد / 250px لياسمين، والخطوة العمودية الآمنة ≈ 110px.

## 🔧 ملاحظات تقنية

- **نموذج الشبكة:** `HOST` هو مصدر الحقيقة (authoritative)، يخطو المحاكاة بخطوة ثابتة (`60Hz`) ويرسل snapshot كل ~20Hz؛ الـ `GUEST` يرسل إدخاله فقط ويعرض الحالة مع إعادة بناء تلقائية عند تبدّل المرحلة.
- **PeerJS cloud signaling** تُستخدم للاتصال الأولي فقط؛ بيانات اللعب كلها نظير-لنظير (WebRTC DataChannel) — زمن استجابة منخفض جداً.
- **حلّ المشاكل:** إن لم يتّصل الطرفان، تأكّدا أن كليكما على إنترنت، وأنّ رمز الغرفة صحيح (يبدأ بـ `SYO-`)، وأنّ المتصفح يدعم WebRTC (كل المتصفحات الحديثة). أحياناً جدران الحماية/الشبكات المغلقة تمنع WebRTC — جرّبا تشغيل كل جهاز على شبكة مختلفة (مثلاً منزل + 4G).
